# 品項全流程工時成本 —— 執行計畫

> 2026-09-29 起討論，2026-10-06 版面定案、開始動工。
> 每一步完成後回報，遇到問題就停下來討論，有共識才繼續。

## 目的

把「產品工時及製成率統計」（製造、充填）與「包裝產能」（成品包裝）兩邊的資料接起來，
讓每個品項從 **製造 → 充填 → 包裝** 都有人時數據，用來：

1. 算出各品項的**直接人工標準成本**（人時/千瓶 × 費率）
2. 每月反映效率異常的品項，**要求製造單位找出問題、提出改善**（系統只反映狀況，不做處理紀錄）
3. 試算任一品項做 N 瓶的各段人時與成本，做 ROI 評估

## 三、兩層模型：9 月以前沒有製造日期，系統一樣能用

| 層 | 用途 | 需要製造日期嗎 | 可用期間 |
|---|---|---|---|
| **品項 × 月份（標準層）** | 標準工時、效率指數、損失人時、異常地圖、成本試算、ROI | **不需要**。製造、包裝各自按月加總，各除以自己的產量 | 製造 2024/10 起；包裝人時 2026/3 起 |
| **生產批（實際層）** | 批次成本卡、製造→包裝間隔天數、全流程批次控制圖 | **需要** | 2026/10 起 |

受影響的只有三個「批次」功能，而且都標示清楚：

- **批次控制圖**：9 月以前的點只含製造＋充填（每點仍是一個生產批）；10 月起加上包裝，成為全流程批次
- **批次成本卡**、**製造→包裝間隔天數**：10 月起才有資料

其餘功能（每月總覽、異常地圖、標準成本、成本試算、ROI、資料健康度）**全部用品項×月份的資料計算，與製造日期無關**。

## 四、計算方法

| 指標 | 公式 |
|---|---|
| 工段分鐘（製造、充填） | （結束 − 開始）＋ 前置；完整涵蓋 12:00–13:00 才扣 60 分。人·分 ＝ 分鐘 × 人數。O 欄不同只提醒，不影響計算 |
| 包裝人時 | 工時（起訖推算）× 人數；沒填人數不納入 |
| 人時/千瓶 | 人時 ÷ 產量 × 1,000（製造、充填用成品數；包裝用包裝瓶數） |
| 標準 | 基準期（2026/3–8）各月 人時/千瓶 的**中位數**，三段分開。**每半年檢討**，不每月變動 |
| 效率指數 | Σ標準人時 ÷ Σ實際人時 × 100；≥95 正常、85–95 注意、<85 異常 |
| 損失人時 | 實際 − 標準；全廠合計只加總比標準慢的品項 |
| 人工成本 | 人時 × 費率（畫面輸入） |
| 離群批次 | 以**每鍋人時**判定：同品項 ≥ 8 場，修正 z ≥ 3.5 且偏離中位數 ≥ 35%，最多剔除 10%（沿用製成率系統，已驗證兩邊同為 62 場） |
| 結案 | 成品數已填才算結案；未結案的月份標「暫定」 |
| 納入標準的門檻 | 製造結案率 ≥ 95%、包裝 0 天漏登（沒填人數的包裝批次逐批排除，不擋月份） |
| 共用作業時段 | 兩品項一列只有開始、一列只有結束 → 合併後依**鍋數**分攤 |
