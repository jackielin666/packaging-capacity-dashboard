# 包裝產能與效率分析

資料來源：`包裝工時記錄表_2026.08.28.xlsx`（122 個工作表，109 個有資料）

- **儀表板**　`../index.html`　全品項、異常清單、品項鑽取、排程試算
- **規劃報告**　`plan.html`　分析前提、關鍵發現、方法論說明

## 每月更新（四步，約 5 分鐘）

```bash
python3 analysis/scripts/extract.py <當月xlsx路徑>   # 解析 → analysis/rows.json
python3 analysis/scripts/audit.py                    # 檢核，有「必須修正」就先回報
python3 analysis/scripts/payload.py                  # 彙總 → analysis/payload.json
python3 analysis/scripts/build.py                    # 灌回 index.html
```

`build.py` 只替換 `index.html` 裡 `/*PAYLOAD:START*/ … /*PAYLOAD:END*/` 之間那段，
版面與程式碼不會被動到，可以重複執行。

需要 `openpyxl`：`pip install openpyxl`

## 檔案

| 檔案 | 用途 |
|---|---|
| `scripts/extract.py` | 解析 xlsx，還原年份、處理混包寫法，逐列輸出 |
| `scripts/audit.py` | 資料檢核，分「必須修正」與「僅供判讀」兩級 |
| `scripts/payload.py` | 計算所有指標與六條偵測規則 |
| `scripts/build.py` | 把 payload 灌回儀表板 |
| `rows.json` | 中間檔（1,571 筆逐批次紀錄） |
| `payload.json` | 儀表板用的彙總結果 |

## 分析前提

這些前提決定了數字怎麼算，改了要重跑：

- **年份**　包裝日期欄無年份。109 個工作表全部依 10月→8月 排序、零筆違反，
  據此還原為 **2025-10-01 ~ 2026-08-26**。
- **工時**　＝（結束 − 起始）÷ 60，**掛鐘小時，不是人工時**。無作業人數欄位，
  因此所有「效率」數字代表線體速率，不代表人均產出。
- **不新增欄位**　假設每次生產人數固定、不良率不納入，單純比較各品項包裝效率。
- **短批次**　全部納入計算，不排除；僅在散佈圖上以空心點標記。
- **混包**　瓶數欄如 `A200/B209` 代表同批混包兩種規格，加總處理（409 瓶）。

## 主要指標

| 指標 | 定義 |
|---|---|
| 產能 | 瓶數 ÷ 工時 |
| 每千瓶工時 | 1000 ÷ 產能（儀表板主指標，可直接乘接單量） |
| 相對工時強度指數 | 工時佔比 ÷ 產量佔比 ＝ 全廠平均產能 ÷ 該品項產能。<br>**只表示比全廠平均慢幾倍，須與工時佔比兩維度並用** |
| P75 目標 | 該品項各批次產能的第 75 百分位（自己跟自己比） |
| 可省工時 | 目前工時 − 全數達 P75 所需工時 |
| 效率指數 | 以各品項全年平均回推的應有工時 ÷ 實際工時 × 100，<br>已扣除產品組合變動，100 = 與全年平均同水準 |
